## Assignment 2 Description 
My personal portfolio using Node.js, ExpressJS, and EJS templating engine. My website uses Express Generator with EJS views, Express routes, seperate public asset folders and header & footer partials.

## Portfolio Pages
Home, About Me, Projects, Contact Me

## Structure
- app.js: express app config
- routes/index.js: routes for the 4 pages
- views: ejs templates for portfolio pages 
- views/partials/: header & footer
- public/stylesheets/: portfolio css
- public/images/: about me image
- public/videos/: intro video

## Technologies
Node.js, ExpressJS, EJS, Bootstrap, Font-Awesome, CSS, Javascript
